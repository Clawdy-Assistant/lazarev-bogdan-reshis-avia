# Картинки

- `hero.webp`: небо с облаками и самолётом для синего блока и экранов входа. Центр оставлен свободным под заголовок.
- `aer.webp`, `led.webp`, `kgd.webp`, `ovb.webp`, `mrv.webp`: иллюстрации направлений для `Destinations`, соотношение сторон 4:3.
- `landing.webp`: большой самолёт над облаками для первого экрана лендинга, слева свободно под текст.
- `step-1.webp`, `step-2.webp`, `step-3.webp`: иллюстрации трёх шагов лендинга.
